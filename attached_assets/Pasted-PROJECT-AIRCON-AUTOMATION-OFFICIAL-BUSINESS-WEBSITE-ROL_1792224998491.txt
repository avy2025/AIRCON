8. RESPONSIVE DESIGN — MANDATORY
==================================================

The website must work properly on:

1. Desktop and laptop screens
2. Tablets
3. Mobile phones

Do not simply shrink the desktop layout to fit smaller screens.

Implement responsive layouts with appropriate breakpoints.

DESKTOP:

- Preserve the Figma layout as closely as possible.
- Maintain the intended content width and whitespace.
- Keep navigation aligned and readable.
- Preserve the relationship between hero text and imagery.
- Avoid unnecessary stretching of content.

TABLET:

- Adjust columns, spacing, and typography where necessary.
- Ensure images and text fit comfortably.
- Prevent navigation items from overlapping.

MOBILE:

- Replace the desktop navigation with a functional hamburger menu
  when appropriate.
- Ensure the logo remains visible and correctly sized.
- Stack hero content vertically when necessary.
- Keep headings readable without excessive line breaks.
- Make buttons easy to tap.
- Allow buttons to stack vertically if needed.
- Ensure images fit within the viewport.
- Convert horizontal metric layouts into suitable stacked or
  multi-column layouts.
- Ensure forms are comfortable to use on a touchscreen.
- Prevent text, cards, buttons, and images from overflowing.
- Maintain consistent spacing and alignment.
- Ensure the footer is usable on smaller screens.

Use fluid layouts, CSS Grid, Flexbox, responsive typography,
and sensible breakpoints.

Do not use fixed widths that cause horizontal scrolling.

Do not use absolute positioning for entire page layouts when
responsive layout techniques are more appropriate.

The website must not have horizontal overflow at common viewport
widths, including approximately 320px, 375px, 390px, 768px,
1024px, 1366px, and 1440px.

Verify the actual mobile layout rather than assuming that
responsive CSS will work automatically.
